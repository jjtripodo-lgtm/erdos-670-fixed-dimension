# Sharpening the finite Erdős 670 parameter witness to 0.6554

Discovery note, 16 October 2026. This is a new **paper-level corollary** of the five-condition finite criterion in Section 5 of the existing manuscript. The published Lean endpoint still certifies only its original constants.

## Claim

For every integer n >= 36354, the criterion implies an n-point distance-separated configuration in R^81794 with diameter strictly below (3277/5000)n² = 0.6554n².

For every m >= m0=18177 and k >= 2 choose:

- s = 2639/2500
- a = 3/8
- L = 28
- C = 305
- K = 1038m
- rational lower bound tau0 = 999999/1000000.

Set gamma=1-a²/8, lambda=(1-1/L)gamma, and tau=sqrt(1-1/[s(K+1)]).

All five conditions are established by the **exact rational** tests in `research/finite670_6554_certificate.py`:

1. tau>tau0 and tau0*s*lambda>1 (C1).
2. K>=m and K>=16384 H_m² (C2).
3. 1038*s³>4C (C3).
4. C²*m0>(84s²/a)²*(1039), hence C4 for all m>=m0 (C4).
5. C*a*gamma>4L (C5).

For (C2), H_m0<16 by dyadic blocks. For every integer m>=4, H_m>=2, and
`(H_(m+1)/H_m)^2 <= (1+1/(2(m+1)))² <= 1+1/m`.
Thus H_m²/m is nonincreasing for m>=4. It suffices to check
`1038*m0 >= 16384*16²`, as the exact script does.

The criterion gives mk points in dimension 3m-1 and diameter at most
`[s³*(1038m+m(m-1)/2)+s²/(2tau)]k²`.
For n>=2m0, take k=floor(n/m0), m=ceil(n/k), delete mk-n points, and pad to 3*27265-1=81794 dimensions. Because n<=mk<(1+1/m0)n, the resulting normalized diameter is strictly below

```
beta = [s³*(1/2+(1038-1/2)/m0)
        +s²/(2*tau0*m0²)]*(1+1/m0)²
     = 0.6553324... < 3277/5000 = 0.6554.
```

This improves the earlier 0.656 witness with unchanged n threshold and dimension, but does not change the published Lean theorem or claim independent verification. No GitHub Actions were used.

The parameters lie close to the C1 fine-digit threshold, and C3 limits further reduction of the offset. Next work should optimize the coupled local-radius and macro-offset geometry, or move beyond the existing five-condition template.
