# A sharper 0.6552 coefficient in the original fixed dimension

Research result, 16 October 2026. Derived from the manuscript's **existing finite criterion**, not a new Lean-checked endpoint.

**Claim (conditional on the established finite criterion):** For every integer n >= 36354, there is a distance-separated n-point set in R^81794 with diameter < (819/1250)n² = 0.6552n².

For every m >= 18177 and k >= 2, take the following exact rational witness:

- s = 1055725/1000000
- a = 3763/10000
- L = 28
- C = 303
- K = 1031m
- tau_lower = 999999/1000000.

The derived gamma = 1-a²/8 and lambda=(1-1/L)gamma satisfy the five conditions of Section 5:

1. The actual tau = sqrt(1-1/(s(K+1))) is strictly above tau_lower, and tau_lower*s*lambda > 1.
2. K >= m and K >= 16384 H_m². The dyadic bound H_18177 <= 16 gives the base inequality. For m >= 4, H_m >= 2 and (H_(m+1)/H_m)² <= (1+1/[2(m+1)])² <= 1+1/m, so H_m²/m is nonincreasing. The base test suffices.
3. 1031*s³ > 4C.
4. C²*18177 > (84*s²/a)²*1032. Since K+m=1032m, this proves C4 for every m>=18177.
5. C*a*(1-a²/8) > 4L.

Every comparison is rational and checked in [finite670_6552_certificate.py](finite670_6552_certificate.py), which also prints the margins.

The criterion then gives mk points in R^(3m-1) with diameter at most
`[s³*(1031m+m(m-1)/2)+s²/(2tau)]k²`.

For arbitrary n>=36354, set k=floor(n/18177) and m=ceil(n/k). Then 18177<=m<=27265, n<=mk<(1+1/18177)n. Delete excess points and pad to R^81794. The diameter coefficient is strictly bounded by

```
beta = [s³*(1/2+(1031-1/2)/18177)
        +s²/(2*tau_lower*18177²)]*(1+1/18177)²
     = 0.6551120553766707... < 819/1250 = 0.6552.
```

This improves the earlier 0.6554 certificate without changing dimension or threshold. The tightest constraints are C1 and C5, so this is a parameter-level improvement rather than a new geometric mechanism.
